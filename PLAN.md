# Termaff — план разработки

Бесплатный минималистичный SSH-клиент для Android (аналог Termius).
Цель MVP: серверы → SSH → нормальная клавиатура (свайпы!) → быстрые команды.
Дизайн: `интерфейс.png` (тёмная тема, мятный акцент, карточки, нижняя навигация).

## 1. Стек (минимум зависимостей)

| Задача | Выбор | Почему |
|---|---|---|
| Язык/UI | Kotlin + Jetpack Compose + Material 3 | Современный стандарт, меньше кода, чем View/XML |
| Терминал | `org.connectbot:termlib` (Compose, libvterm через JNI, Apache-2.0) | Готовый Compose-компонент: VT100/xterm, 256/truecolor, выделение, зум, resize |
| SSH | `org.connectbot:sshlib` 2.2.x (форк Trilead, Apache-2.0) | Зрелая, в проде у ConnectBot: Ed25519, ChaCha20, AES-GCM, SFTP. Новая Kotlin-версия `org.connectbot.sshlib` 0.4 пока сыровата |
| Хранение | 1 JSON-файл + встроенный `org.json` | Вместо Room: данных мало; без лишних зависимостей |
| Секреты | Android Keystore, AES-GCM | Пароли и приватные ключи шифруются ключом, не покидающим устройство |
| Навигация | состояние в `MainActivity` | Одна Activity, без библиотеки навигации |

**Без:** DI-фреймворков, Room, Retrofit, аналитики, рекламы, Firebase.
**Запасной вариант**, если termlib/sshlib не подойдут на спайке: `termux terminal-view` (через `AndroidView`) + `mwiede/jsch`.

## 2. Главная фича — клавиатура со свайпами

**Проблема:** терминалы (Termius, Termux, ConnectBot) отдают IME `inputType = TYPE_NULL`
или «visible password», поэтому клавиатура отключает подсказки, автозамену и **свайп-ввод**.

**Решение — два режима ввода, переключаются одной кнопкой:**

1. **Строка ввода (по умолчанию)** — обычный `TextField` под терминалом (как на макете: «Введите команду…»).
   Полноценный IME: свайпы, автозамена, голосовой ввод, вставка, редактирование перед отправкой.
   `Enter`/кнопка ▶ → отправка `text + "\r"`. Пустая строка + Enter → просто `\r`.
   Автозамена первой буквы на заглавную выключена (`KeyboardCapitalization.None`).
2. **Прямой режим** — нажатия сразу уходят в PTY (для `vim`, `htop`, `mc`, паролей sudo).
   Включается автоматически, если сервер перешёл в alternate screen (`\e[?1049h`), и выключается при выходе.

**Панель клавиш** (горизонтальный скролл): `Ctrl` `Alt` `Esc` `Tab` `↑` `↓` `←` `→` `|` `~` `/` `-` `⋯`.
Ctrl/Alt — «липкие» (одно нажатие = модификатор для следующей клавиши).
↑/↓ в строке ввода листают локальную историю команд.

**Жесты по терминалу:** pinch — размер шрифта; горизонтальный свайп — ←/→; long-press — выделение/копирование.

## 3. Экраны (MVP)

Нижняя навигация: **Серверы · Команды · Настройки**.

1. **Серверы** — поиск, карточки (иконка, имя, `user@host:port`, теги, точка-статус), ⋮ меню (изменить/копировать/удалить), FAB «+».
2. **Сервер (редактор)** — имя, хост, порт, пользователь, аутентификация (пароль / ключ), теги, команда при входе.
3. **Терминал** — шапка (имя, IP, ⋮), termlib, панель быстрых команд (чипы), строка ввода + ▶, панель клавиш.
4. **Команды** — плитки быстрых команд (иконка, название, команда) + «Сценарии» (несколько шагов подряд, кнопка ▶).
   Команда глобальная или привязана к серверу. Запуск: вставить в строку ввода или выполнить сразу.
5. **Настройки/Ключи** — генерация Ed25519, импорт OpenSSH-ключа, показать/скопировать публичный ключ; шрифт, размер, тема терминала.

Позже (не MVP, по макету): «Обзор» с метриками (CPU/RAM/диск через `exec` чтения `/proc` без агентов), SFTP-браузер, Docker-панель.

## 4. Архитектура (1 модуль, ~15 файлов, цель ≤ 2500 строк)

```
app/src/main/java/app/termaff/
  MainActivity.kt        — NavHost, тема, нижняя навигация
  data/Models.kt         — Server, Snippet, Scenario, KnownHost (@Serializable)
  data/Store.kt          — чтение/запись JSON, StateFlow<AppState>, атомарная запись
  data/Vault.kt          — Keystore AES-GCM: encrypt/decrypt секретов
  ssh/Session.kt         — connect/auth/shell/resize/write/close; поток байтов → термлиб
  ssh/Sessions.kt        — реестр активных сессий (живут дольше экрана)
  ssh/SessionService.kt  — foreground service: соединения не рвутся в фоне
  ui/Theme.kt            — цвета/типографика из макета
  ui/ServersScreen.kt, ServerEditScreen.kt
  ui/TerminalScreen.kt   — терминал + InputBar + KeysBar
  ui/CommandsScreen.kt, SettingsScreen.kt
```

Поток данных: `Store (StateFlow)` → экраны; `Session` ↔ `TerminalEmulator` (read-loop в `Dispatchers.IO`).
Без ViewModel-слоя там, где хватает `remember` + `Store`; ViewModel только для терминала (переживает поворот).

## 5. Безопасность

- Host key: TOFU — при первом подключении показать SHA256-отпечаток и спросить; при смене — жёсткое предупреждение, соединение блокируется.
- Секреты только в зашифрованном виде (Keystore), `android:allowBackup="false"`, исключение из data extraction.
- Никакого логирования паролей/вывода терминала. Опционально `FLAG_SECURE` (скрыть из скриншотов/недавних).
- Разрешения: только `INTERNET`, `FOREGROUND_SERVICE`, `POST_NOTIFICATIONS`.
- R8/minify в release; подпись APK своим ключом (keystore вне репозитория).

## 7. Риски

- **termlib/sshlib молодые (0.3.x)** — API может меняться; снижаем спайком на этапе 1 и фиксацией версий.
- **Foreground service на Android 14+** требует тип; для SSH подходит `specialUse` (для Google Play нужно обоснование; для GitHub/F-Droid не важно).
- **libvterm = нативный код** — APK с несколькими ABI; собирать split-APK по ABI для малого размера.
